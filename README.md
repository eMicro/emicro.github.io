# eMicro — GitHub Pages

A Persian (RTL), responsive, dark landing page for eMicro. It uses plain HTML, CSS and JavaScript and can be hosted directly on GitHub Pages.

## Deploy

1. Extract this archive.
2. Put `index.html` in the root of the `eMicro/emicro.github.io` repository.
3. Commit and push to the `main` branch.
4. In **Settings → Pages**, keep deployment from `main` / root.
5. Open `https://emicro.github.io/` or your verified custom domain.

## Customize

- Update the page copy and project descriptions in `index.html`.
- Replace `https://github.com/eMicro` if your GitHub organization/user URL changes.
- Add real project URLs to the project cards.
- The Vazirmatn font is loaded from Google Fonts; a system sans-serif fallback is included.

No build step, package manager, or framework is required.
